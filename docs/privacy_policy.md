# Swipeat プライバシーポリシー（公開前ドラフト）

最終更新日：2026年8月25日

この文書はIssue 23の実装とGoogle Play申告内容をそろえるための公開前ドラフトです。正式公開前に、運営者の法人名・所在地・問い合わせ窓口・データ保持期間を確定し、公開URLへ掲載します。

## 1. 取得する情報と利用目的

| 情報 | 利用目的 | 送信先・保存先 |
| --- | --- | --- |
| 端末の位置情報 | 周辺の営業中店舗を検索し、距離を計算する | Google Places API、アプリ内の一時処理 |
| Googleアカウント識別子・プロフィール | Premium権限をアカウントへ紐付ける | Firebase Authentication、権限バックエンド |
| Premium購入トークン | Google Play購入状態を検証し、権限を同期する | 権限バックエンド、Google Play Developer API |
| 広告識別子・広告配信情報 | Free区切り画面のバナー広告を配信し、計測する | Google Mobile Ads（同意が必要な地域ではUMP同意後のみ） |
| Placesの店舗情報・写真 | 候補カードとDecision画面を表示する | Google Places APIから取得。アプリの候補プールで一時保持 |

Freeの「今すぐ提案」はログインなしで利用できます。通常のスワイプ画面、写真、店舗情報に広告は表示しません。Premium、Trial、complimentary、developer entitlementでは広告SDKへ広告リクエストを行いません。

## 2. 同意・選択肢

Google AdMobはGoogle User Messaging Platform（UMP）で同意状態を更新し、広告をリクエストできる状態になった場合だけ初期化します。同意情報の更新またはSDK初期化に失敗した場合は広告を読み込みません。対象地域ではアプリ内の「広告・プライバシー設定を変更」から選択を見直せます。

## 3. 保持・削除・第三者提供

権限バックエンドはアカウント識別子、権限状態、開始・終了日時、購入検証に必要な識別子を、権限の有効性確認に必要な期間だけ保持します。決済カード情報はSwipeatで取得・保存しません。Google/Firebase/AdMob/Placesの各サービスへの送信は、上記目的に必要な範囲に限ります。

アカウント削除、情報開示、訂正、広告設定に関する問い合わせは、公開時に記載する問い合わせ先で受け付けます。削除依頼の本人確認と処理期限は、運営者確定後にこの文書へ追記します。

## 4. 変更と問い合わせ

重要な変更はアプリ内画面と公開URLで告知します。正式公開前に、運営者名・所在地・問い合わせメールアドレス・有効な公開URLを必ず設定します。
