# Issue 14: Premium v1.0 追加絞り込みのスコープ確認

## 結論

Premium v1.0 の確定コアは次の機能とする。

- 広告非表示。
- 最大20店舗の連続スワイプ。
- Swipeat 独自ジャンルの `primaryGenre` 完全一致。
- 条件不一致時に他ジャンルを混ぜない空状態。

Issue 14 で候補となっていた次の条件は、プロダクトオーナーが採否を決めるまで実装しない。

- 詳細距離設定。
- 評価指定。
- 価格帯指定。
- チェーン店を含む / 少なめ。
- 個人店優先。

## 理由

- 指示書で Premium v1.0 の機能範囲が未確定である。
- 条件を追加すると、Places FieldMask、分類品質、候補不足時の緩和ルール、UI、課金価値の検証範囲が同時に広がる。
- ジャンル精度を優先する原則を崩さず、追加条件は独立した後続 Issue として実装できる設計を維持する。

## 実装上の扱い

- `PremiumCandidateFilter` は現時点で `primaryGenre` のみを判定する。
- `RestaurantClassification` の `style`、`brand`、`isChain`、`rating`、価格情報は将来の絞り込み用データとして保持できるが、検索条件には使用しない。
- 候補不足時にチェーン制限や評価条件を自動緩和する処理は追加しない。
- 追加条件を採用する場合は、条件ごとに受け入れ条件・候補不足ルール・テストを持つ別 Issue を起票する。

## 保留解除条件

Product Decision `PD-03` に、採用する条件、候補不足時の緩和ルール、対象プラットフォームを記録した時点で、追加フィルタ Issue を再開する。
